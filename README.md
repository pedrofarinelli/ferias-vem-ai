# Guia Férias Vem Aí

Dicas de Orlando e Miami reunidas a partir dos Reels e posts compartilhados no grupo “Férias vem aí”, organizadas por tema (parques Disney, parques Universal, compras, consumo, alimentação, planejamento e passeios).

Site: https://pedrofarinelli.github.io/ferias-vem-ai/

Página única em HTML, sem dependências. Os filtros funcionam só com HTML e CSS; busca e favoritos usam JavaScript e ficam salvos no próprio aparelho.
